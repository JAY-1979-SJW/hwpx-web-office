## 목표

카탈로그 뷰어(`build_hwpx_form_catalog_toc.py` 생성 HTML)의 검색창이 사이드바 옆 좁은 툴바에 끼어 있어 도서관 카탈로그 느낌이 나지 않던 문제를 도서관 OPAC 표준 레이아웃(WorldCat류)으로 재배치한다.

## 건축공사 비유

기존 현장 안내소(검색창)가 통로 한쪽 구석 좁은 부스에 끼어 있어 방문객이 못 찾고 지나치던 것을, 정문 로비 전체폭에 안내 데스크를 새로 놓고 그 아래에 분류 패널(좌측 패싯)과 전시장(결과 목록)을 나란히 배치하는 재시공이다. 기존 배관·전기 배선(필터/정렬/페이지네이션 로직)은 그대로 두고 데스크와 전시장 위치만 옮긴 구조 변경이다.

## 수정 파일

- `scripts/ops/build_hwpx_form_catalog_toc.py`

## 변경 이유

- 검색은 화면 최상단 전체폭(`#topbar`)에 고정 — 브랜드 + 통검색 입력(돋보기 아이콘) + 전체/입력가능 건수를 함께 배치
- 그 아래를 `#body`로 감싸 사이드바(패싯)와 `#main`(결과) 2단 구조로 분리
- 기존 필터/정렬/페이지네이션 로직은 id 변경 없이 DOM 위치만 이동해 그대로 재사용
- 필터 상태 없이도 처음부터 페이지네이션(1-50/38,165건)이 눈에 들어오도록 개선

## 검증 결과

playwright로 라이트/다크 테마와 필터 적용 상태를 재확인하여 정상 동작 확인.
