## 목표

저장소 분류 계약(classification contract) 결과를 바탕으로, 매니페스트 승격 후보(manifest promotion candidates)를 자동으로 수집·분류하는 빌더를 신설한다. 이를 통해 안정 경로 매핑 파일이 명시적 모듈 매니페스트 항목으로 승격되기 전 검토 단계를 공식화한다.

## 수정 파일

| 파일 | 역할 |
|------|------|
| `scripts/ops/build_hwpx_repo_manifest_promotion_candidates.py` | 신규 — 승격 후보 빌더 본체 |
| `scripts/ops/gate_hwpx_form_auto_fill_fail_fast.py` | 기존 게이트에 manifest promotion 게이트 연동 |
| `scripts/ops/install_hwpx_form_auto_fill_persistent_gates.py` | 영구 게이트 설치 목록에 신규 게이트 등록 |
| `tests/test_hwpx_form_auto_fill_fail_fast_upload_dashboard.py` | fail-fast 대시보드 테스트 보강 |
| `tests/test_hwpx_form_auto_fill_persistent_gates.py` | 영구 게이트 테스트 보강 |
| `tests/test_hwpx_repo_manifest_promotion_candidates.py` | 신규 — 빌더 단위 테스트 |

## 변경 이유

- 분류 계약 게이트(`gate_hwpx_repo_classification_contract`)가 반환하는 `manifestPromotionCandidates` 목록을 소비하는 전용 빌더가 없어, 승격 대상 파일을 수작업으로 추적해야 했다.
- 빌더가 후보를 `sourceFiles / testFiles / auditFiles` 세 키로 분류하고 미해결(unresolved) 후보를 명시적으로 집계함으로써, 승격 전 검토 기준을 계약으로 강제한다.
- 보고서 출력 시 절대경로·원본 파일명·PII 유출을 차단하는 `_no_leak` 검증을 내장해 보안 요건을 충족한다.

## 검증 결과

- `PASS_HWPX_REPO_MANIFEST_PROMOTION_CANDIDATES` 판정 조건: 계약 게이트 PASS + 모든 후보의 `moduleId` 및 `targetKey` 해결 완료
- `FAIL_CONTRACT_GATE` / `FAIL_PROMOTION_TARGET_UNRESOLVED` 두 실패 코드로 원인 구분
- 보고서 3종(summary JSON, candidates JSON, module breakdown JSON) + Markdown 요약 자동 생성

## 다음 단계

> **건축 비유:** 이번 공정은 각 세대(파일)의 입주 전 사전점검표(manifest promotion candidates)를 자동 생성하는 시스템을 설치한 단계다. 감리검사(classification contract)를 통과한 세대만 점검표에 올라오며, 미완공 세대(unresolved)가 남아 있으면 준공검사(promotion)가 자동 차단된다.
