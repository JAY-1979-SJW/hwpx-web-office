## 목표

카탈로그 목차 뷰어(`catalog_toc_viewer.html`)에서 서식 행을 클릭하면
해당 서식의 원본을 좌표 뷰어(`coord_view.html`)로 바로 열람할 수 있도록
두 뷰어를 연결한다.

## 수정 파일

- `frontend/web_office_viewer/coord_view.html` — `?src=<sourcePath>`
  쿼리 파라미터로 넘어오면 기존 `loadLayout()`을 자동 호출해 원본을 바로
  렌더링하도록 추가(신규 프리미티브 없음, 기존 hwpx-layout API 재사용).
- `scripts/ops/build_hwpx_form_catalog_toc.py` — 목차 조회 SQL에
  `source_path` 컬럼을 추가하고, 사이드바(발행기관/문서유형/서식종류)
  필터 + 검색이 되는 자체완결형 `catalog_toc_viewer.html`을 생성. 행 클릭 시
  `sourcePath`를 새 탭의 `coord_view.html?src=...`로 전달.

## 변경 이유

목차(38,165건)에서 개별 서식을 눈으로 확인하려면 지금까지는 파일 경로를
직접 찾아 별도로 열어야 했다. 목차 → 원본 뷰어를 한 번의 클릭으로 이어
붙여 카탈로그 탐색 작업(현황 파악, 결함 표본 확인 등)의 왕복 시간을
줄인다.

## 검증 결과

로컬 API 서버(`editor_api_route.create_app()`) 기동 후 playwright로
목차 → 행 클릭 → 새 탭에서 원본(lineseg 좌표 그대로, 한컴 미사용)이
5페이지·138줄로 정상 렌더링되는 것까지 end-to-end 확인.
