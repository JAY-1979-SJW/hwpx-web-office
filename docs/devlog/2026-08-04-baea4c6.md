## 목표

카탈로그 목차 뷰어(`build_hwpx_form_catalog_toc.py` 생성 HTML)의 밋밋한
표 나열형 UI를 디자인 토큰 기반으로 재작업. 기능 변경 없이 가독성과
완성도만 개선.

## 변경 이유

기존 화면은 색상·여백·타이포 위계가 없는 원시 표 형태였고, 다크모드
대응이 전무했음. 기능(사이드바 필터 → 행 클릭 → 원본 뷰어 연결)은
그대로 두고 시각적 완성도만 별도 공정으로 분리해 처리.

## 수정 파일

- `scripts/ops/build_hwpx_form_catalog_toc.py` — `_render_viewer_html()` 내 인라인 CSS 전면 재작성

## 주요 변경 내용

- CSS 커스텀 프로퍼티(`--bg`, `--text`, `--accent` 등)로 색상 토큰화,
  `prefers-color-scheme` + `data-theme` 속성 기반 다크모드 지원
- 사이드바: 활성 항목 좌측 accent 보더 표시, 브랜드 영역 추가
- 입력가능 여부를 pill 배지로 표시 (기존 텍스트 컬러 구분 → 배지)
- 통계 영역 강조(`<b>` 태그), `tabular-nums`로 숫자 정렬 개선
- 테이블 헤더 sticky 고정 유지 + 위계 강조(대문자, letter-spacing)
- 스크롤바 커스텀 스타일 추가

## 검증 결과

- 기능 로직(필터링/검색/행 클릭 라우팅) 미변경 — CSS/마크업 속성만 수정
- 기능 회귀 리스크 낮음 (스타일 전용 diff)
