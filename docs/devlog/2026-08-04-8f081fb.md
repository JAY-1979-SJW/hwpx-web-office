## 목표

카탈로그 목차 뷰어를 실사용 관점에서 섹션별(사이드바/툴바/필터/표)로 재검토해, 정보 밀도는 낮추고 조작 명확성은 높인다.

## 건축공사 비유

준공된 모델하우스 안내데스크를 다시 손본 격이다. 발행기관·문서유형·서식종류 세 안내판을 한 벽에 욱여넣던 것을 각 안내판별 탭으로 나눠 방문객이 한 번에 하나씩만 보게 했고, 현장 배관도(서버 주소) 같은 기술자용 표시는 "설정" 패널 뒤로 치웠다. 견본 세대 목록에서는 이미 필터링된 축(예: 발행기관)을 행마다 반복해서 강조 표시하지 않도록 하고, 클릭 가능한 행에는 "↗ 원본 열기" 안내 문구를 손잡이처럼 붙였다.

## 수정 파일

- `scripts/ops/build_hwpx_form_catalog_toc.py`

## 변경 이유

- 사이드바 3축(발행기관/문서유형/서식종류) 동시 노출은 스크롤이 길어져 원하는 축을 찾기 어려웠다 → 탭 분리로 축당 스크롤 단축, "전체" 항목 추가로 필터 해제 경로 명시
- 원본 뷰어 서버 주소 입력창은 디버그용인데 검색창과 나란히 노출되어 주의를 분산시켰다 → "⚙ 서버 설정" 토글 뒤로 숨김
- 활성 필터가 사이드바 강조 표시로만 드러나 어떤 필터가 걸려 있는지 한눈에 파악하기 어려웠다 → 필터 칩(배지+×)으로 명시하고 클릭 한 번에 해제 가능하게 함
- 표에서 필터축과 동일한 열이 모든 행에 같은 값으로 반복 표시되어 시야를 낭비했다 → 해당 열 뮤트 처리, form_id는 내부 식별자이므로 모노스페이스로 격하
- 행 클릭으로 원본이 열린다는 사실이 커서 모양 외에는 드러나지 않았다 → 호버 시 "↗ 원본 열기" 힌트 추가

## 검증 결과

CSS/HTML 구조 변경 위주 스타일 커밋으로, 별도 감리검사(audit) 스크립트 실행 로그는 커밋 diff에 포함되지 않음. 브라우저 목측 확인 필요.
