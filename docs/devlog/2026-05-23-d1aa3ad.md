## 변경 이유

`api_batch` 모듈의 소스·테스트 파일이 단일 파일만 선언되어 있던 상태에서, 실제 구현에 참여하는 파일(`hwpx_form_auto_fill_module_communication_manifest.json`, `hwpx_form_autofill_api_route.py`, `test_hwpx_form_autofill_api_route.py`)이 누락되어 있었다. 이를 매니페스트에 추가 선언하여 승격 대상에서 제외(promotion 완료)함.

건축 비유: 세대(파일) 준공도면에 누락된 설비 배관(소스·테스트 파일)을 추기 기재하고, 해당 세대를 미시공 목록에서 제거한 상태.
