## 목표

`field_mapping` 모듈의 소스·테스트 파일 목록을 매니페스트에 정식 등록(승격)하고,
승격 완료된 모듈이 후보 목록에서 제거되는지 계약 테스트로 검증한다.

## 수정 파일

- `scripts/ops/audit_hwpx_form_auto_fill_module_manifest.json`
- `tests/test_hwpx_repo_classification_contract.py`
- `tests/test_hwpx_repo_manifest_promotion_candidates.py`

## 변경 이유

> 건축 비유: 골조 검사를 통과한 세대(파일)를 준공 도면(매니페스트)에 정식 등재하는 단계.

`field_mapping` 모듈에 실제로 사용 중인 파일들이 매니페스트에 등록되지 않은 채 "승격 후보" 상태로 남아 있었다.
이를 정식 등재하여 후보 풀에서 제거하고, 전체 안정 경로 매핑 파일 수를 37개로 확정한다.

| 항목 | 변경 전 | 변경 후 |
|------|---------|---------|
| `field_mapping` sourceFiles | 1개 | 3개 |
| `field_mapping` testFiles | 1개 | 6개 |
| 계약 테스트 수치 고정 | `>= 1` | `== 37` |
| 승격 후 후보 제거 검증 | 없음 | `test_06` 추가 |

## 검증 결과

- `test_hwpx_repo_classification_contract`: `stablePathMappedFiles == 37`, `manifestPromotionCandidates == 37` 수치 고정 통과
- `test_hwpx_repo_manifest_promotion_candidates`: 승격된 `field_mapping`이 `moduleBreakdown`에서 제거됨 확인 (`test_06` 신규)
- 기존 `test_06`, `test_07`은 번호 순서 조정 (`test_07`, `test_08`)
