## 목표

저장소 분류 계약(repo classification contract) 게이트를 fail-fast 파이프라인에 통합하여, 파일 분류 계약 위반 시 이후 공정을 즉시 중단한다.

## 수정 파일

- `scripts/ops/gate_hwpx_form_auto_fill_fail_fast.py` — fail-fast 파이프라인에 `repo_classification_contract` 게이트 단계 추가; 실패 시 조기 반환 처리 및 이후 모든 `_finish` 호출에 페이로드 전파
- `scripts/ops/gate_hwpx_repo_classification_contract.py` — 저장소 분류 계약 게이트 신규 구현
- `scripts/ops/gate_hwpx_repo_existing_file_classification.py` — 기존 파일 분류 게이트 보조 수정
- `scripts/ops/install_hwpx_form_auto_fill_persistent_gates.py` — 영속 게이트 설치 로직에 신규 게이트 반영
- `tests/test_hwpx_form_auto_fill_fail_fast_upload_dashboard.py` — fail-fast 대시보드 테스트 업데이트
- `tests/test_hwpx_form_auto_fill_persistent_gates.py` — 영속 게이트 테스트 업데이트
- `tests/test_hwpx_repo_classification_contract.py` — 분류 계약 게이트 신규 테스트 추가

## 변경 이유

기존 파이프라인은 개별 파일 분류(신규/기존)를 검사하는 게이트만 존재했다. 저장소 전체 분류 계약을 별도 게이트로 분리하여, **모듈 로그 계약 검사 직후·기존 파일 분류 검사 이전** 시점에 명시적으로 차단점을 삽입했다. `canonical_report_dir` 플래그를 도입해 기본 보고 경로 여부에 따라 신규 파일 목록 전달을 분기 처리했다.
