## 목표

커밋마다 개발 이력을 자동으로 기록하는 post-commit 훅 설치.
`logs/change_history.jsonl` 및 `docs/devlog/*.md` 파일을 커밋 직후 자동 생성한다.

## 수정 파일

- `scripts/hooks/post_commit.py`

## 변경 이유

매 커밋 후 수동으로 devlog를 작성하는 부담을 제거하기 위해 자동화 훅을 도입.
Claude Code CLI 사용 가능 시 AI가 diff를 분석해 한국어 devlog를 작성하고,
CLI 미사용 환경에서는 stub(빈 템플릿)을 자동 생성해 공백 이력을 방지한다.

## 검증 결과

- `ALLOW_POST_COMMIT_AUTO_COMMIT=1` 미설정 시 자동 commit 비활성화 — 안전 기본값 확인
- 시크릿 패턴(`sk-`, `ghp_`, `AIza` 접두어) regex 마스킹 로직 포함
- `docs: devlog` 메시지로 시작하는 커밋은 훅 재진입 방지(무한 루프 차단) 확인
- diff 8,000자 초과 시 truncate 처리 확인
