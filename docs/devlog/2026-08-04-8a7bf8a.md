# fix: post-commit devlog 훅 미발동 결함 수리 — .git/hooks → .githooks 경로 정정

- 작업일시: 2026-08-04
- 작업자: skyjw
- 관련 브랜치: feat/hwpx-coord-fidelity
- 관련 커밋: 8a7bf8a

## 목표

`core.hooksPath=.githooks` 설정과 실제 훅 설치 경로(`.git/hooks/`)의 불일치를 바로잡아 post-commit devlog 자동 기록이 실제로 발동하도록 수리한다.

## 수정 파일

- `.githooks/post-commit` (신규 — `.git/hooks/post-commit` 내용을 그대로 이전)

## 변경 이유

건축 비유로 말하면, 준공검사 자동 기록계가 처음부터 배선이 안 된 위치에 설치되어 있었던 셈이다. `core.hooksPath`는 5월 22일 훅 도입 시점부터 `.githooks`로 지정돼 있었지만, post-commit 훅 스크립트만 기본 경로인 `.git/hooks/`에 설치되어 있어 실제로는 한 번도 실행되지 않았다. 반면 `pre-commit`·`pre-push`는 처음부터 올바른 `.githooks/` 경로에 있어 정상 동작했다. 그 결과 도입 이후 이 저장소의 모든 커밋에서 `devlog`/`change_history.jsonl` 자동 기록이 누락됐고, 유일하게 남아있던 로그 1건은 훅 설치 커밋 자체에서 수동으로 남겨진 것이었다. 로직 자체는 문제가 없었으므로 내용은 그대로 옮기고 설치 위치만 정정했다.

## 검증 결과

경로 정정 커밋(8a7bf8a) 이후 발생하는 커밋부터 post-commit 훅이 정상 발동해 devlog 자동 기록이 재개되는지 확인 필요 (본 커밋 자체는 훅 미발동 상태에서 생성되었으므로 다음 커밋에서 발동 여부 확인).

- 5월 22일~8월 4일 사이 누락된 devlog 이력을 소급 복원할지 여부 검토(선택).
